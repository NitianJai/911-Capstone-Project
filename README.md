# 911-Capstone-Project

 911 Calls Data Capstone Project hosted on GitHub—likely a Jupyter notebook analyzing emergency call data (latitude, timestamp, call type, etc.), similar to widely shared projects using Pandas, Matplotlib, Seaborn

These notebooks typically include:

Data exploration: Checking dataset structure (~99,000 entries, fields like title, zip, twp, timeStamp) 
arXiv

Feature engineering: Creating a Reason column by extracting "EMS", "Fire", or "Traffic" from title 

Descriptive statistics: Identifying top zip codes and townships with the most calls 

Temporal analysis: Parsing timestamps into Hour, Month, and Day of Week; visualizing trends through countplots, heatmaps, and line plots 

Heatmaps & cluster maps: Highlighting busiest hours of day and busiest days/months
